```
Binary Search

Subject: Data Structures and Algorithms

Difficulty: Beginner to Intermediate

1. Definition

Binary Search is an efficient searching algorithm used to find an element in a sorted array.

Instead of checking every element one by one, Binary Search repeatedly divides the search space into two halves.

2. Important Requirement

Binary Search requires the input data to be sorted.

For example: 

```

[10, 20, 30, 40, 50, 60, 70]
```

The array is sorted in ascending order, so Binary Search can be applied.

3. How Binary Search Works

  1. Find the middle element of the current search range.
  2. Compare the middle element with the target.
  3. If the middle element is equal to the target, the search is successful.
  4. If the target is smaller than the middle element, search in the left half.
  5. If the target is larger than the middle element, search in the right half.
  6. Repeat until the element is found or the search range becomes empty.

4. Example

Consider the sorted array: 

```

[10, 20, 30, 40, 50, 60, 70]
```

Suppose we want to search for 60.

Step 1

The middle element is 40. Since 60 is greater than 40, we search the right half. 

```

[50, 60, 70]
```

Step 2

The middle element is 60. The target is found.

5. Algorithm

```

binarySearch(array, target):

```
low = 0
high = length(array) - 1

while low <= high:

    mid = low + (high - low) / 2

    if array[mid] == target:
        return mid

    else if array[mid] < target:
        low = mid + 1

    else:
        high = mid - 1

return -1

6. Python Implementation

```

def binary_search(arr, target):
low = 0
high = len(arr) - 1

```
while low <= high:
    mid = low + (high - low) // 2

    if arr[mid] == target:
        return mid

    elif arr[mid] < target:
        low = mid + 1

    else:
        high = mid - 1

return -1
```

arr = [10, 20, 30, 40, 50, 60, 70]

target = 60

result = binary_search(arr, target)

print(result)

```
7. Time Complexity

Case Time Complexity
Best Case O(1)
Average Case O(log n)
Worst Case O(log n)

The space complexity of the iterative implementation is O(1).

8. Binary Search vs Linear Search

Feature Binary Search Linear Search
Data Requirement Sorted Can be unsorted
Best Case O(1) O(1)
Worst Case O(log n) O(n)
Approach Divide and conquer Sequential search

9. Advantages

  • Very efficient for large sorted datasets.
  • Has O(log n) worst-case time complexity.
  • Requires only constant extra space in iterative form.
  • Simple and widely used algorithm.

10. Disadvantages

  • The data must be sorted.
  • Maintaining sorted data can be expensive.
  • It is not always suitable for linked lists.

11. Real-World Applications

  • Searching in sorted databases.
  • Dictionary and word lookup systems.
  • Finding values in sorted datasets.
  • Competitive programming.
  • Searching ranges and boundaries.

12. GATE Important Points

  • Binary Search works on sorted data.
  • Worst-case time complexity is O(log n).
  • Iterative Binary Search uses O(1) auxiliary space.
  • Recursive Binary Search uses O(log n) stack space.
  • Binary Search is based on the divide-and-conquer idea.

14. Summary

Binary Search is a divide-and-conquer searching algorithm that repeatedly divides a sorted search space into two halves. It provides O(log n) worst-case time complexity and is much faster than Linear Search for large sorted datasets.
```
